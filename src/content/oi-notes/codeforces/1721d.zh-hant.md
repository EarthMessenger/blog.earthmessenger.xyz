title: CF 1721D Maximum AND
---

給定序列 $a$，$b$，$b$ 可以任意排列。令 $c_i = a_i \oplus b_i$，則價值則為 $c_1
\& c_2 \& c_3 \& \cdots \& c_n$，求價值最大值。

如果答案的某一位是 $1$，則 $a$ 該位的 $0$ 和 $1$ 數量必然和 $b$ 該位的 $1$ 和
 $0$ 數量分別相同。同樣的，如果答案 $ans$ 可行，則 $a_i \& ans$ 得到的所有值的數
量與 $\neg b_i \& ans$ 得到的所有值的數量相同（$\neg$ 當作取反符號）。從高位到
低位，判斷 $ans$ 當前位為 $1$ 是否可行，可行則或上。

```cpp
void solve()
{
    int n;
    std::cin >> n;
    std::vector<unsigned int> a(n), b(n);
    for (auto &i : a) std::cin >> i;
    for (auto &i : b) std::cin >> i;
    auto check = [&a, &b](unsigned int ans) {
        std::map<unsigned int, int> cnt;
        for (auto i : a) cnt[i & ans]++;
        for (auto i : b) cnt[~i & ans]--;
        for (auto i : cnt) {
            if (i.second != 0) return false;
        }
        return true;
    };

    unsigned int ans = 0;
    for (int i = 31; i >= 0; i--) {
        if (check(ans | (1 << i))) {
            ans |= (1 << i);
        }
    }
    std::cout << ans << std::endl;
}
```
