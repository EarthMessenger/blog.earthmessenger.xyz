## 解析

首先，這個期望可以表示成：$\sum_{i=1}^{k} i \times P(i)$，其中 $P(i)$ 表示在第
$0$ 剛好在第 $i$ 次操作被刪掉的機率。考慮令 $P'(i) = \sum_{j=i}^{k}P(i)$，即在
第 $i$ 次操作還沒移除 $0$ 的機率，然後這個期望就可以表示成：$\sum_{i=1}^{k}
P'(i)$。我們的任務就變成了求解 $P'(i)$。

令 $f(i, j)$ 表示，考慮前 $i$ 個棋子，已經操作了 $j$ 次的機率。由於我們要求 $0$
處的棋子沒有被移除，那麼對於任意 $i$，$0$ 到 $i$ 至多被操作 $i-1$ 次，否則就會
把 $1$ 移除。可以得到轉移方程：

$$
f(i, j) = \sum_{k=0}^{j} f(i - 1, j - 1) \times \binom{j}{k} \times \left(\frac{s_{i}}{n}\right)^k
$$

其中，$s_{i}$ 是第 $i$ 個棋子到第 $i+1$ 個棋子中間的距離。

最後，答案就是 $\sum_{i=0}^{k} f(k, i)$。

## 實現

```cpp
int main()
{
	set_io("game");

	int n, k;
	std::cin >> n >> k;
	std::vector<int> a(k), s(k);
	for (auto &i : a) {
		std::cin >> i;
		i--;
	}

	for (int i = 0; i < k; i++) {
		s[i] = ((a[(i + 1) % k] - a[i]) % n + n) % n;
	}

	std::vector<mint> fact(k + 1), ifact(k + 1);
	fact[0] = 1;
	for (int i = 1; i <= k; i++) fact[i] = fact[i - 1] * i;
	ifact[k] = fact[k].inv();
	for (int i = k; i >= 1; i--) ifact[i - 1] = ifact[i] * i;
	auto binom = [&fact, &ifact](int n, int m) -> mint
	{
		if (m < 0 || m > n) return 0;
		return fact[n] * ifact[m] * ifact[n - m];
	};

	mint INVN = mint{n}.inv();
	std::vector<mint> f(k + 1);
	f[0] = 1;
	mint ans = 0;
	for (int i = 1; i < k; i++) {
		std::vector<mint> g(k + 1);
		mint base = mint{s[i]} * INVN;
		for (int j = 0; j < i; j++) {
			mint pow = 1;
			for (int t = 0; j + t <= i; t++) {
				g[j + t] += f[j] * binom(j + t, t) * pow;
				pow *= base;
			}
		}
		f = std::move(g);
	}

	for (int j = 0; j <= k; j++) {
		ans += f[j];
	}

	std::cout << ans.val() << std::endl;
}
```
