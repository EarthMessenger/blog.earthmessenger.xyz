## 解析

貢獻的計算式子可以轉化成：$\max\left\{r_i - l_j, r_j - l_i\right\}$。也就是說對
於每一個配對正好有一個貢獻為 $+r$，一個貢獻為 $-l$，對於所有二元組就是恰好有一
半貢獻為 $+r$，其他為 $-l$。於是考慮貪心，先假設全部貢獻 $+r$，在減去 $r+l$ 的
前 $\frac{n}{2}$ 小的和。

```cpp
int main()
{
	int n;
	scanf("%d", &n);
	std::vector<std::pair<int, int>> a(n);
	for (auto &[l, r] : a) scanf("%d%d", &l, &r);

	long long ans = 0;
	for (auto [_, r] : a) ans += r;

	std::vector<long long> lr;
	for (auto [l, r] : a) lr.emplace_back(l + r);
	std::sort(lr.begin(), lr.end());

	for (int i = 0; i < n / 2; i++) {
		ans -= lr[i];
	}

	printf("%lld\n", ans);
}
```
